Design Doc v0.5
===============

XLSX 書式・UI仕様（MVP / 互換性重視）
-------------------------

* * *

0. 設計方針（最重要）

------------

### 前提ソフト

* **Microsoft Excel**

* **LibreOffice Calc**

* **Google Sheets（閲覧）**

→ **高度なExcel専用機能は使わない**  
（コメント、スパークライン、PowerQuery、テーブルオブジェクト等は不使用）

* * *

1. シート共通レイアウト仕様

---------------

### 1.1 行・列の固定（可視性）

* **第1行：固定（Freeze）**

* **第1列：固定（Freeze）**

→ LibreOffice / Excel / Sheets すべて対応

* * *

### 1.2 ラベルセルの書式（指定要件）

#### 対象

* **第1行（ヘッダ行）**

* **第1列（銘柄識別列）**

#### 書式

| 項目   | 値                                      |
| ---- | -------------------------------------- |
| 背景色  | **濃紺**（RGB: 24, 36, 60 / HEX: #18243C） |
| 文字色  | **白**（#FFFFFF）                         |
| フォント | デフォルト（指定しない）                           |
| 太字   | ON                                     |
| 罫線   | 下線・右線のみ（薄灰）                            |

※ RGB指定は LibreOffice でも安定  
※ フォント指定しないことでOS差異を回避

* * *

### 1.3 フィルタ・ソート対応

* **第1行にオートフィルタを必ず設定**

* 各数値列は
  
  * 数値型で出力（文字列化しない）
  
  * 欠損は空欄

→ 全指標で  
**ソート／条件付きフィルタ可能**

* * *

2. 列構成（CORE_TOPシート例）

--------------------

### 2.1 列順（左→右）

#### A. 識別（固定列）

1. `listing_id`

2. `code`

3. `name`

4. `market`

5. `listing_age_days`

#### B. 価格・流動性

6. `close`

7. `volume`

8. `turnover_est`

#### C. 指標（視線集中ゾーン）

9. `rs_long_pct`

10. `rs_short_z`

11. `delta_rs_short`

12. `vol_z`

#### D. 補助

13. `flags`

* * *

### 2.2 列幅（推奨・絶対ではない）

| 列                | 幅   |
| ---------------- | --- |
| listing_id       | 14  |
| code             | 8   |
| name             | 18  |
| market           | 10  |
| listing_age_days | 10  |
| close            | 10  |
| volume           | 12  |
| turnover_est     | 14  |
| rs_* / vol_z     | 12  |
| flags            | 18  |

LibreOfficeでも破綻しない無難な幅。

* * *

3. 指標の「ひとこと説明」の付け方（互換性重視）

-------------------------

### 結論

**列名の直下（第2行）を“説明行”として使う**

* * *

### 3.1 構造

* **第1行**：列名（ラベル）

* **第2行**：説明（文字列）

* **第3行以降**：データ

#### メリット

* コメント・ノート不要

* LibreOffice / Excel / Sheets すべてOK

* CSV化しても説明行として保持できる

* * *

### 3.2 説明行の書式

| 項目   | 値           |
| ---- | ----------- |
| 背景色  | 薄紺（#E6EBF2） |
| 文字色  | 濃紺（#18243C） |
| フォント | 標準          |
| 折り返し | ON          |
| 高さ   | やや高め（2行想定）  |

* * *

### 3.3 指標説明文（確定案）

| 列名             | 説明文                                       |
| -------------- | ----------------------------------------- |
| rs_long_pct    | **過去約1年の株価パフォーマンス順位。高いほど中長期で市場に評価されている。** |
| rs_short_z     | **直近の相対的な強さ。プラスが大きいほど短期で注目が集まりつつある。**     |
| delta_rs_short | **短期相対強度の変化量。正なら勢いが加速中。**                 |
| vol_z          | **出来高の異常度。大きいほど投資家の関心が急浮上。**              |
| turnover_est   | **概算売買代金。資金の集まりやすさの目安。**                  |

※ 文言は

* 短い

* 解釈を限定しすぎない

* 投資助言にならない  
  を満たすよう調整済み。

* * *

4. 並び順・視線設計

-----------

### 4.1 初期ソート（書き出し時）

* `rs_long_pct` DESC

* 同値の場合 `vol_z` DESC

→ 開いた瞬間に  
**「強くて注目されている銘柄」**が上に来る

* * *

### 4.2 条件付き書式（MVPで使ってよい範囲）

#### 使用OK

* 単色の背景ハイライト

* 閾値ベース（例：rs_long_pct >= 80）

#### 使用NG

* カラースケール

* データバー

* アイコンセット  
  （LibreOfficeで崩れやすい）

* * *

### 4.3 推奨ハイライト（任意）

| 条件                | 書式    |
| ----------------- | ----- |
| rs_long_pct >= 80 | 背景：薄緑 |
| vol_z >= 2.0      | 背景：薄橙 |
| flags 非空          | 背景：薄赤 |

※ 色は淡く。意味は README に記載。

* * *

5. READMEシートの最小テンプレ（再掲＋補足）

--------------------------

READMEには **「操作方法」も一言入れる**。

例：

> **操作のヒント**  
> ・第1行のフィルタで並び替え・絞り込みが可能です  
> ・第2行は指標の説明です（並び替え対象外）  
> ・数値が空欄の銘柄は履歴不足または除外条件に該当します

* * *

6. CSVとの整合ルール

-------------

* CSVは **説明行なし**

* XLSX第2行の説明は
  
  * CSVには含めない

* 列名・列順は **完全一致**

→ XLSX ⇄ CSV の往復が壊れない。

* * *
