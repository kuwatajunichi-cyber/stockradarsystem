Web UI の表ヘッダー・グラフ凡例・ホバー見出し・ツールチップの第一版（改訂2）。 改訂2の短い理想案をデプロイ済み画面の表示名と解説ツールチップに適用した。 表示名の正本は Markdown。YAML の proposed と formal_name は Markdown に合わせ、Markdown を YAML の文言へ戻さない。 web_ui_v1 の置換ではない。XLSX の列名は変えない。 live_gate_5d は open のまま。Phase 5 overall は in_progress。Issue #93 は OPEN。

表ヘッダーとグラフ凡例が、同じ数値を別名で呼んでいる。窓の数字だけ、または `Zscore` だけでは、何の量かも分からない。初版の理想案（相対31、平滑相対31、断面日）は名前を揃えたが、「相対力」は relative strength の直訳で、金融工学に馴染みのない人には何と何を比べた量か伝わらない。改訂2 では、表示名と正式名を日常語に言い換え、解説（ツールチップ）を利用者向けの読み方だけにし、製品や仕組みの事実は「仕様メモ」に分けた。デプロイ済み画面の列名は短い理想案（31日RS、売買代金異常、当日の値動き）である。

## 命名の方針

- 表・凡例・ホバーは同じ指標を同じ短い名で呼ぶ。
- 短い名は、何をどう比べた量かが分かる語で組む（例: 指数比 31日リターン ＝ 比べ方＋期間＋量、売買代金Z ＝ 量＋比べ方）。窓の数字だけ、または Z だけにしない。
- リターンは「その期間にどれだけ上がったかの割合。下がればマイナス」の意味で使い、共通文で定義する。値上がり率・騰落率は表示名に使わない。
- 指数比の後ろは、指数比の値から作った量（加速・加速Z・安定度）だけ「の」で受ける。価格側で作ってから指数と比べる量（31日リターン、75日線の傾き）は「指数比 ＋ 空白 ＋ 量」にする。「指数比の75日線」と書くと、指数比を平均した線と読まれる。
- 表示名と正式名に専門語・内部語を使わない。避ける語と言い換えは glossary に従う。専門語は解説の末尾に「専門用語では〜」として残す。
- 正式名は、それだけ読めば意味が取れる日常語の完全な名前にする。コードや契約文書の呼び名は internal_name に書く。
- ベンチ名は列に入れない。指数比の系列は、ツールバーの比較指数（TOPIX / 日経平均）に追従する。
- 期間は営業日数で書き、解説に暦のおおよその長さを添える（31営業日≈1か月半、63≈3か月、126≈半年、252≈1年）。
- 解説は「何を、何と比べて、どう測るか」→「0・正・負の読み方」→「似た指標との違い」→「注意」の順に書く。読み方であり、売買の指示を書かない。
- 解説（explanation）は利用者向けの読み方だけを書く。製品や仕組みの事実（XLSX との対応、描画の縮尺、既定の表示有無、データの組み立て方、現行名との対応）は spec_notes に分け、ツールチップには出さない。
- 既定で隠れている列（default_visible: false）も、列パネルで表示したときは同じ形式のツールチップを出す。表や凡例に出ない語（対象銘柄など）も同じ形式で理想案・正式名・解説を持つ。表示場所は surface に書く。
- 数値の多くは小数1桁。正は +、ほぼゼロは ±0。
- 指数比の定義・符号・単位は families.index_relative に一度だけ書く。指数比の列のツールチップは、その共通文を先に出し、各列の個別文を続ける。%表記は前日比(%) だけ。
- Z は「普段とのズレを標準偏差で測った値」。偏差値に直すと 50＋10×Z。
- 売買代金Zの棒だけ高さは Z÷5。表とホバーの数字は生のZ。

| ベンチ / ベンチマーク | 比較指数 | ベンチは一般には座席。比較指数なら「指数比」の相手だと一語でつながる。 |

## 指数比の性質（共通文）

対象列のツールチップは、この共通文を先に出し、続けて各列の個別文（explanation）を出す。（YAML `families.index_relative`）。

> 指数比 ＝ この銘柄のリターン − 比較指数のリターン（同じ期間、終値どうし）。 リターンは、その期間にどれだけ上がったかの割合で、下がればマイナス。 市場全体の動きを基準に、この銘柄の成績を比べる値。正なら指数より良く、負なら悪く、0 なら同じ。 割り算ではなく引き算なので、指数が下がった期間でも符号の意味は変わらない。 株価が下がっていても、指数より下げ幅が小さければ正になる。 +0.1 は10%分の差（指数 +5%・銘柄 +15% → +0.10。指数 −10%・銘柄 −4% → +0.06）。%表示ではない。

| 指数のリターン | 銘柄のリターン | 指数比 | 読み方 |
| --- | --- | --- | --- |
| +5% | +15% | +0.10 | 指数より良い |
| −10% | −4% | +0.06 | 株価は下がったが、指数ほど下がらなかったので正 |
| −10% | −10% | ±0 | 指数と同じ |
| −10% | −15% | −0.05 | 指数より悪い |

## 解説（ツールチップ文案）

利用者向けの読み方だけ。製品や仕組みの事実は次節の仕様メモに置く。指数比の列は共通文を先に出す。

### 既定で見える列

- **コード** — 東証の4桁の証券コード。
- **銘柄名** — 銘柄の名称。
- **お気に入り** — 自分で保存したお気に入りリストに、この銘柄が入っているかどうか。 チップはリストの印で、強い・弱いを表す指標ではない。
- **当日の値動き** — 基準日の始値・高値・安値・終値から、その日の値動きの形を短い言葉で表したもの。 陽線（終値が始値より高い）、陰線（その逆）、上ヒゲ・下ヒゲ（一時的に大きく動いて戻した）、 上窓・下窓（前日の値幅から離れて始まった）、S高・S安（ストップ高・ストップ安。1日の値幅制限に達した疑い）など。
- **売買代金Z** — 基準日の売買代金（終値×出来高）が、この銘柄の普段（直近60営業日）と比べてどれだけ珍しい多さかを表す値。 ズレは標準偏差を1として測る。学校の偏差値と同じ考え方で、偏差値＝50＋10×Z。 0 が普段どおり、+1 でやや多め、+2 以上は普段ほとんど見ない多さ、負は普段より少ない。 株価ではなく売買代金のZ。「売買代金倍率」（普段の何倍か）とは別。
- **指数比の加速Z** — 「指数比の加速」が、この銘柄の普段（直近60営業日）と比べてどれだけ珍しい大きさかを表す値。 売買代金Zと同じ物差しで、0 が普段どおり、+2 以上は普段ほとんど見ない強い加速、−2 以下はその逆（偏差値＝50＋10×Z）。 加速そのものの大きさではないので、加速が小さくても、この銘柄の普段がもっと小さければ大きな値になる。
- **指数比の加速** — 「指数比 31日リターン」−「指数比 252日リターン」。直近約1か月半の指数比が、過去1年の指数比よりどれだけ高いか。 正なら、最近のほうが指数に対して勢いがある（例: 1年では指数に負けていたが、直近は勝っている）。負ならその逆。 グラフの線の傾きのことではない。「指数比の加速Z」（普段と比べた珍しさ）とも別。
- **指数比 31日リターン** — （共通文に続けて）31営業日（約1か月半）のリターンの指数比。
- **指数比 63日リターン** — （共通文に続けて）63営業日（約3か月）のリターンの指数比。
- **指数比 126日リターン** — （共通文に続けて）126営業日（約半年）のリターンの指数比。
- **指数比 252日リターン** — （共通文に続けて）252営業日（約1年）のリターンの指数比。「指数比の加速」は、指数比 31日リターンからこの値を引いた差。
- **指数比 75日線の傾き** — （共通文に続けて）この銘柄と比較指数それぞれの「75日線」（直近75営業日の終値の平均をつないだ線）が、31営業日でどれだけ上がったかの割合の差。 終値の代わりに、日々の上下をならした線で比べるので、流れとしてどちらが強いかが出る。 単位は指数比 31日リターンと同じで、1日あたりの傾きではない。指数比を75日で平均した線でも、75日リターンでもない。
- **ニュース候補** — 売買代金が急増した日に関係しそうなニュースの候補（最大3件）。原因と断定したものではない。 材料が見つからないときは「材料不明・需給起因疑い」などの文になる。
- **調査用まとめ** — この銘柄の基本情報（基準日・コード・銘柄名）と、当日の売買代金・値動きの指標を1行のテキストにまとめたもの。 自分で調べるときや AI に質問するときに、そのまま貼り付けて使える。結論は含まない。

### 既定では隠れている列

- **連動分を除く指数比 252日リターン** — 1年（252営業日）のリターンから、「この銘柄が指数にどれだけ連動して動くか」（β、ベータ）×「指数のリターン」を引いた値。 βが1.5なら、指数が1%動くとこの銘柄は平均1.5%動くという意味。 指数比 252日リターンは連動の強さを1とみなして引くのに対し、こちらは銘柄ごとの連動の強さを考慮する。 正なら、指数に連動して動いた分を除いても上がっている。
- **指数比の安定度** — 直近63営業日（約3か月）について、毎日の「この銘柄の前日比 − 比較指数の前日比」の平均を、そのばらつき（標準偏差）で割った値。 指数を上回る日が安定して続くほど正に大きく、下回る日が続くほど負に大きい。 日によってまちまちだと、平均が同じでも絶対値は小さくなる。 %でも倍率でもなく、指数比 63日リターンとは別の量。専門用語では情報比率。
- **パーフェクトオーダー日数** — 終値の25日・75日・200日移動平均線が、短い線ほど上に並んだ状態（25日線 > 75日線 > 200日線）が、基準日まで何営業日続いているか。 上昇の並びだけ数え、逆の並び（下降パーフェクトオーダー）は数えない。0 はその並びではない。 220営業日分（1年弱）の株価がない銘柄は空欄。
- **前日比(%)** — 前営業日の終値に対する基準日終値の変化率。+3.0 なら前営業日より 3% 高い。 この列だけ値が%で、指数比の小数（0.1＝10%分）とは単位が違う。指数との比較は含まない。
- **売買代金倍率** — 基準日の売買代金が、この銘柄の直近60営業日平均の何倍か。1.0 が普段どおり、3.0 なら普段の3倍、0.5 なら半分。 「売買代金Z」と同じく普段と比べる値だが、こちらは倍率で、Zは珍しさの度合い。

### 画面の他のラベル

- **基準日** — 表とグラフがそろえている営業日。画面のすべての数値は、この日の終値までのデータで計算している。 「最終更新」はデータが確定した時刻で、基準日とは別。
- **比較指数** — 「指数比〜」が比べる相手。TOPIX（東証の幅広い銘柄の指数）か日経平均（代表的な225銘柄の指数）。 切り替えると指数比の列とグラフが入れ替わる。 売買代金Z、当日の値動き、前日比(%)、売買代金倍率、パーフェクトオーダー日数は変わらない。
- **最終更新** — いま見ているデータが確定した時刻（日本時間）。基準日そのものではない。
- **指数比がすべてマイナスの銘柄を除外** — 指数比 31日・63日・126日・252日リターンと、指数比 75日線の傾きがすべてマイナスの銘柄を一覧から外す。 下げ相場でも、指数より下げ幅が小さい銘柄は残る。指数比の加速と売買代金Zは見ない。
- **対象銘柄** — この画面が扱う銘柄の範囲。国内株式のうち、上場して間もない銘柄（約1年分の株価がまだない）と、 売買代金が少なく取引が薄い銘柄を除いたもの。画面の数値はすべてこの範囲の中で計算している。
- **概要（株探）** — 株探（かぶたん）の銘柄概要ページを開く。
- **チャート（株探）** — 株探のチャートページを開く。この画面の指数比グラフとは別。
- **ニュース（株探）** — 株探のニュース一覧を開く。表の「ニュース候補」（売買代金が急増した日の候補）とは別。
- **ニュース候補タブ** — 表の「ニュース候補」と同じ内容を、下段のタブで開く。
- **バフェットコード** — バフェットコードの銘柄ページを開く。この画面のグラフや、表のニュース候補とは別のサイト。
- **みんかぶ** — みんかぶの銘柄ページを開く。この画面のグラフや、表のニュース候補とは別のサイト。
- **Yahoo!ファイナンス** — Yahoo!ファイナンスの銘柄ページを開く。この画面のグラフや、表のニュース候補とは別のサイト。

## 適用時の注意

- conditional-format.js は列キー（z_turnover_60 と rs_acceleration_zscore）でレンジ5を判定する。ヘッダー文字列には依存しない。
- 保存済みお気に入りリスト名「お気入り」はユーザーデータ。表示ラベルの変更と保存名の移行は別作業。
- 特殊フィルタのデプロイ済み文言は「指数比がすべてマイナスの銘柄を除外（31・63・126・252日リターンと75日線の傾き）」。
- デプロイ済みの凡例と YAML の proposed は短い理想案（31日RS、売買代金異常、最長は「75移動平均RS」）である。
- リターンは % 表示が通例だが、本画面の指数比は小数（+0.1 ＝ 10%分）で、1桁表示では約10%分刻みにしかならない。%ポイント表示（+3.4）に変える場合は、web_ui_v1 の数値表示・グラフ軸 [-1,+1]・条件付き書式レンジ 1・XLSX との単位整合を同時に決める。本カタログでは未決。
- 売買代金倍率に 1 倍超で正符号が付く現行表示は「+2.3倍増」と誤読されうる。ラベル適用時に倍率は符号なし表示にする候補。
- 検索の注記はデプロイ済みで「存在しないか、この画面の対象銘柄に含まれません」。用語ボタンの表示は対象銘柄。
- 現行名（31日、RS31、SMA75 RS、Zscore、加速Z）や XLSX 列との対応は spec_notes に書き、解説（ツールチップ）には出さない。
- 列パネルで追加した列（default_visible: false）のヘッダーにも、既定列と同じ仕組みでツールチップを付ける。
