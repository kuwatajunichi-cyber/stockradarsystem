## 1. 目的

日次指標 CSV を Excel に流し込むための **見栄え付きテンプレート**。  
人向けの日本語グループ見出し（1〜2 行目）と、プログラムが参照する **機械可読ヘッダー行**（3 行目）を併用する二段ヘッダー構成。

実装との接点は `scripts/render_sheet/render_sheet.py` および `config/render_sheet.yaml`。

## 3. データシート（TOPIX版 / 日経平均版）共通レイアウト

### 3.1 行の役割

|行|役割|
|---|---|
|**1**|大グループ見出し（日本語）。結合セルあり。背景色でブロックを区切る。|
|**2**|列ごとの日本語ラベル（表示用）。|
|**3**|**機械可読ヘッダー**（CSV 列名と一致させる文字列）。`render_sheet` はこの行を左から空セルまで読み、テンプレ列集合を決める。|
|**4 以降**|データ行。テンプレではサンプル行が含まれる場合あり。|

### 3.2 名前付き範囲（`render_sheet` 契約）

- ブックには **`headerAnchor`** を **ブック全体で 1 つ** 定義し、次の 2 領域を **カンマ区切り**でまとめる（同一セル位置）。
  - `TOPIX版!$A$3`
  - `日経平均版!$A$3`
- 各データシートの **3 行目・A 列**が機械可読ヘッダー先頭であり、ここから左→右にテンプレ列を解決する。
- **注意（テンプレ作成時）**: シートごとに同名 `headerAnchor` を「シートローカル」で重ねる形式にすると、openpyxl では **先頭 1 シート分しか読めない**。必ず上記の **単一のブックレベル定義＋複数領域**にすること。

`.gitkeep` には旧例として `indicators001` が記載があるが、v1.2 ではシート名が上記に置き換わっている。

### 3.3 ウィンドウ枠の固定

- **固定セル: `H4` 相当**（行 4 より上、列 H より左を固定）。
- 横スクロール時も **A〜G 列（日付・コード・銘柄・リンク系など）** が見え続ける想定。

### 3.4 結合セル（1 行目）

| 範囲 | 内容（TOPIX版の例） |
| --- | --- |
| `J1:O1` | 「対TOPIXリターン強度（Relative Strength）」を横断表示。日経版では文言が「対日経平均リターン強度（Relative Strength）」に差し替わる。 |
| `P1:R1` | 「売買代金急増　要因ニュース候補（β）」を横断表示。 |

## 4. 配色・フォント（データシート）

### 4.1 背景色（実測・ARGB）

| 用途 | 塗り `fgColor` | 備考 |
| --- | --- | --- |
| メイン見出しブロック（B〜I 付近の 1〜2 行目など） | `#424352` | 濃い青灰色 |
| ニュース候補ブロック（P〜R の 1〜2 行目） | `#696980` | やや明るい青灰色 |
| 列 A の非表示に近い領域 | 塗りなし / 既定 | フォントは薄灰 `#D9D9D9` が使われるセルあり |

### 4.2 フォント（3 行目・機械可読ヘッダー）

列ごとに次のような差がある（Excel 上のセルスタイル）。

- **Arial 10pt**: `date`（A）、数値・RS 系の多く（B, I〜O など）。
- **Meiryo 10pt**: `name`（C）、`price_text`（H）など日本語が主となる列。
- **Arial 10pt イタリック**: 株探リンク列（D〜G）。
- **Times New Roman 10pt**: ニュースタイトル列（P〜R）のヘッダー表示。

※ openpyxl 上、3 行目の一部セルでは `fill` が未解決で `null` でも、画面上は行スタイルやテーマで濃色背景＋白文字に見える場合がある。

### 4.3 データ行（テンプレのサンプル）

- フォント色の例: `#D9D9D9`（薄いグレー）やテーマ色。
- **セル保護**: サンプルでは `locked=True`。`render_sheet` でシート保護を有効にする際、**`headerAnchor` 対象シートのデータ矩形は書き込み後にロック解除**される（操作可能にするため）。

## 5. 条件付き書式（CSV 流し込み対象列）

`render_sheet` は **セル値のみ**を書き換え、条件付き書式の定義はテンプレート側のまま残す。以下は `indicators_template_v1.2.xlsx` の `xl/worksheets/sheet*.xml` および `xl/styles.xml`（`dxfs`）から読み取った仕様。

### 5.1 カラースケール（3 段・数値系）

**TOPIX版・日経平均版で同一**（条件付き書式ブロックの並び・内容を揃えた）。

|適用範囲（sqref）|主な対応列（機械名）|スケール端点（cfvo）|左端色 → 中間 → 右端色（ARGB）|
|---|---|---|---|
|`L2:O3000`|`rs31_*` 〜 `rs252_*`（L〜O 列）|式 `-1` / `0` / `1`|`#E67C73`（赤系）→ `#FFFFFF` → `#57BB8A`（緑系）|
|`I1:K3000`|`z_turnover_60`、`rs_acceleration_zscore_*`、`rs_acceleration_*`（I〜K 列）|式 `-5` / `0` / `5`|`#E67C73` → `#FFFFFF` → `#57BB8A`|

※ `L2:O3000` は 2 行目（日本語小見出し）から下にかかる。`I1:K3000` は 1 行目からデータ最下行まで。

※ 以前テンプレに残っていた **1 行目 `J1:M1` のカラースケール**、日経側のみの **`J2` 単独**・**`C4` の min/max スケール**は誤設定のため削除済み（見出し行の誤着色・シート間の不一致の原因になっていた）。

### 5.2 文字列に基づく塗りつぶし（列 H / `price_text`）

範囲は **`H1:H3000`**。種類は「セル内テキストに特定の **部分文字列** が含まれる」条件（`SEARCH`）。Excel 上は行ごとに参照がずれる（定義上の式は先頭行 `H1` 基準）。

`styles.xml` の `dxfId` と背景の対応:

| dxfId | 条件（含むテキスト） | セル書式の目安 |
| --- | --- | --- |
| 0 | `陽線` | 塗り `#B8DBC6` |
| 1 | `陰線` | 塗り `#E7C0BA` |
| 2 | `S高` | 背景 `#006342`、フォント白 |
| 3 | `S安` | 背景 `#AD2800`、フォント白 |
| 5 | `構造要因疑い` および `レンジ0`（別ルールだが同一 dxf） | 背景 `#69697F`、フォント白 |

#### 評価の優先順（priority、数値が小さいほど先）

両データシート共通。ブック全体の priority の流れは、**L2 のカラースケール=1** → 列 H のキーワード **2〜5** → **`B4` の非空=6** → **`I1:K3000` のカラースケール=7** → 列 H の **構造要因疑い=8** → **レンジ0=9**。

複数キーワードが同時に成立しうる文言では、**先にマッチした優先度の書式**が使われる。

### 5.3 銘柄コード（列 B）— 単一セル指定

- 範囲 **`B4`** のみに、`LEN(TRIM(B4))>0`（実質「空白でない」）に対する塗り `#B7E1CD`（`dxfId=4`）が付いている。
- **sqref が `B4` のみ**のため、CSV 流し込みで値が入る **5 行目以降の B 列にはこのルールは自動では広がらない**（テンプレ上の見本 1 セル向け）。全行に同様の強調が必要なら、テンプレ側で範囲を `B4:B3000` 等に変更する必要がある。

### 5.4 データシート間の一致

**TOPIX版と日経平均版**について、条件付き書式は **9 個の `<conditionalFormatting>` ブロック**で **XML 上の定義が同一**（誤って残っていた見出し用・日経専用ルールを除き、優先度も揃えた）。

## 9. README シート

- 主に **B 列** に長文。
- 2 行目付近: 「【ご利用にあたって】」など太字見出し。
- 以降: 著作権・利用条件などの箇条書き（全角スペースインデントあり）。
- **`headerAnchor` なし** → `render_sheet` はこのシートを **データ流し込み対象にしない**。

## 10. `config/render_sheet.yaml` との対応

| 設定キー | テンプレート上の意味 |
| --- | --- |
| `link_label_map` | `link_kabutan` 等の **機械列** に対し、セル表示を「概要」「チャート」など **2 行目と揃えた短いラベル** にし、URL はハイパーリンク化。 |
| `hyperlink_source_map` | `event_news_*_title` に別列の URL を埋め込み、タイトルをリンク表示。 |
| `sort_column` / `sort_ascending` | 流し込み前の CSV ソート（テンプレの列名と一致する必要あり）。 |
| `sheet_protection` | 全シート保護。`headerAnchor` 対象シートの書き込み範囲はロック解除。 |

パスワード等の機密は本ドキュメントには書かない（設定ファイル参照）。

## 11. 行数・パフォーマンス上の注意

- データシートの `max_row` は **3000**。`render_sheet` はおおむね同規模を「書式済み範囲」とみなし、超過時に警告ログを出す。
- それ以上の行が必要な場合は、テンプレの事前書式行の拡張としきい値の見直しが必要。
