# 日足形状ガイド

このガイドは、UI上で「日足形状」として表示されるテキストの読み方を、
**基礎編 → 仕組編 → 応用編**の順に段階的に解説します。

仕様の正は実装・[`docs/OHLC_desripter_v1.3.md`](../OHLC_desripter_v1.3.md) とし、本書はユーザー向け説明用です。置き場所の整理は [README.md](README.md) を参照。

---

## はじめに: 30秒でわかる日足形状

日足形状は、1日のローソク足（始値・高値・安値・終値）を**一文で要約**したものです。

> 例: `<極大>長下ヒゲ陽線`
>
> → 「普段より大きい値幅で、一度下げたが買い戻され、引けは買い優勢だった日」

先頭付近の **`<極大>`** や **`<小>`** のように、**`<`（小なり）と `>`（大なり）で囲んだ部分**は、**相対的な値幅（サイズ）**の欄を区切るための表記です（数式やタグ言語の意味はありません）。

日足形状を見ると、次のことが分かります。

- 1日を通した値幅の大きさ（普段より大きいか小さいか）
- 実体とヒゲのバランス（どちらが支配的だったか）
- 引け時点の優勢方向（買いか売りか拮抗か）
- 窓の有無や、制限値幅到達疑いのような日次イベントの有無

日足形状は「その日の値動きの結果」をコンパクトに伝えるためのもので、
出来高やニュースと合わせて使うと解釈の精度が上がります。
限界や注意点はセクション6（応用編）で詳しく解説しています。

## 1. 基礎編: ローソク足の超基本

まずは、日足形状に頻出する単語を押さえます。

### 1-1. 陽線と陰線

- **陽線**: 終値が始値より高い（Close > Open）
  - 引けにかけて買いが優勢だった日
- **陰線**: 終値が始値より低い（Close < Open）
  - 引けにかけて売りが優勢だった日

### 1-2. 実体とヒゲ

- **実体**: 始値と終値の差
  - 長いほど、その日の方向感が強め
- **上ヒゲ**: 高値側に伸びた部分
  - 高いところで売られた痕跡
- **下ヒゲ**: 安値側に伸びた部分
  - 安いところで買い戻された痕跡（= 日中反発）

> 例: `長下ヒゲ陽線` → 下ヒゲが長い＝安値圏で買い戻しがあり、かつ陽線＝引けは買い優勢

### 1-3. 十字線（じゅうじせん）

- 始値と終値がほぼ同じ形
- 売り買いが拮抗し、方向感が出づらいことが多い

> 例: `<小>十字線` → 値幅が小さく、かつ始値≒終値。拮抗・様子見の典型

## 2. 基礎編: 日足形状の読み方

日足形状の文章は、複数の部品を並べた構造です。
左から順に **「サイズ → 形 → 方向」** と読むのが基本です。

### 例1: `<極大>長下ヒゲ陽線`

|部品|意味|
|---|---|
|`<極大>`|その銘柄として値幅が大きい日（角括弧はサイズ部の目印）|
|長下ヒゲ|日中に下げたが下値で買い戻しが入った|
|陽線|引けは買い優勢|

→ 「荒い値動きの中で一度崩れたが、最終的には買い戻された日」

### 例2: `上窓＋長上ヒゲ陰線`

|部品|意味|
|---|---|
|上窓＋|前日レンジから離れて上方向に始まった|
|長上ヒゲ|上値を試したが押し戻された|
|陰線|引けは売り優勢|

→ 「ギャップアップで始まったが高値を維持できず、売りに押された日」

### 例3: `<大>丸坊主陽線`

|部品|意味|
|---|---|
|`<大>`|普段より値幅が大きい（角括弧はサイズ部の目印）|
|丸坊主|ヒゲが短く、ほぼ一方向|
|陽線|引けは買い優勢|

→ 「大きい値幅で、始値から終値まで買いが押し切った日」

## 3. 基礎編: パターン辞書

ここでは日足形状に登場するすべての部品を一覧にします。

> **まず3つだけ覚えれば十分:**
>
> 1. **陽線 / 陰線** — その日の決着方向
> 2. **長下ヒゲ / 長上ヒゲ** — 日中の押し戻しの痕跡
> 3. **`<極大>` / `<小>`** — 普段比の値幅の大きさ
>
> この3つを押さえておけば、ほとんどの日足形状を直感的に読めます。
> 残りは必要に応じて辞書引きしてください。

### 3-1. 方向系

|部品|日中の価格挙動|需給の見方|
|---|---|---|
|**陽線**|終値が始値を上回る|引けにかけて買い優勢|
|**陰線**|終値が始値を下回る|引けにかけて売り優勢|
|**十字線**|始値と終値が近く、方向が中立|拮抗・様子見の地合い|

### 3-2. ヒゲ系

|部品|日中の価格挙動|需給の見方|
|---|---|---|
|**長上ヒゲ / 上ヒゲ**|上値を試したが押し戻された|高値帯で売り圧力が確認された|
|**長下ヒゲ / 下ヒゲ**|下値を試したが切り返した|安値帯で買い需要が確認された（日中反発）|
|**長上下ヒゲ / 上下ヒゲ**|上下に振れ幅が出た|方向が定まりにくく、短期筋の攻防が強い|

> 例: `長上下ヒゲ十字線` → 上下に大きく振れたが、結局始値付近に戻った。乱高下だが決着つかず

### 3-3. 実体系

|部品|日中の価格挙動|需給の見方|
|---|---|---|
|**丸坊主**|ヒゲが短く、ほぼ一方向で推移|一方向に需給が偏りやすい|
|**長**|実体が長く、方向感が明確|方向感強め|
|**中**|実体は中庸|中立|
|**短**|実体が小さい|迷いが強め|

### 3-4. 値幅（レンジ）系

|部品|日中の価格挙動|需給の見方|
|---|---|---|
|**`<極大>` / `<大>`**|普段より大きい値幅|参加者間で評価差が拡大し、売買が活発化|
|**`<小>` / `<極小>`**|普段より小さい値幅|売り買いが拮抗し、方向感が出にくい|

### 3-5. ギャップ（窓）系

|部品|日中の価格挙動|需給の見方|
|---|---|---|
|**下窓＋**|当日のレンジが前日より上にずれて離れている|寄り付き時点で買い需要が売りを上回っていた可能性|
|**上窓＋**|当日のレンジが前日より下にずれて離れている|寄り付き時点で売り需要が買いを上回っていた可能性|

> 例: `上窓＋長下ヒゲ陽線` → 下に離れて始まり、さらに下値を試したが、安値圏で買いが入り引けは陽線。悪い初動を跳ね返した形

### 3-6. 特殊ラベル（注意喚起）

通常の足型とは別に、以下の注意喚起ラベルが表示されることがあります。

- S高タッチ疑い / S安タッチ疑い
- S高(安)タッチ後張付き疑い
- S高寄天疑い / S安寄底疑い
- S高(安)完全張り付き疑い
- レンジ0
- 構造要因疑い

「疑い」は断定ではなく、日足データ（OHLC）から機械的に抽出したスクリーニングフラグです。
各ラベルの詳しい意味はセクション4-3（特殊・注意喚起ラベルの詳細）を参照してください。

## 4. 仕組編: 判定ロジックの考え方

ここからは、日足形状がどのように作られるかをロジック寄りに説明します。

### 4-1. 入力データ

- 当日の日足: Open / High / Low / Close
- 前日終値（ギャップや制限値幅判定に利用）

### 4-2. 分解の軸

日足形状は大きく次の4軸で組み立てられます。

1. **サイズ（相対値幅）**: その日が普段比で大きいか小さいか
2. **形状（実体・ヒゲ比率）**: どの部位が支配的か
3. **方向（陽線/陰線）**: 引け時点の優勢側
4. **異常/特殊ラベル**: 先に優先判定される注意信号

この分離により、「値幅の大きさ」と「足の形」を混同せず読めます。

> 例: `<極大>長下ヒゲ陽線` は、**サイズ部**（先頭の `<` `>` で囲んだ極大）・**形状**（長下ヒゲ）・**方向**（陽線）に分解できる

### 4-3. 特殊・注意喚起ラベルの詳細

特殊ラベルは、通常の形状分析より**先に確認すべき注意信号**です。
特に制限値幅関連は、日足データ上では該当して見えても、最終的な解釈にはJPXの公表情報や取引所ルール、当日の公式開示・売買状況の確認が必要です。
実務上は「疑い」を見た段階で、断定せず一次スクリーニングとして扱い、公式情報で裏付けを取る運用を推奨します。

#### 制限値幅関連

- **S高タッチ疑い**
  - 日中の価格挙動: 高値が制限値幅上限に到達
  - 需給の見方: 買い圧力が非常に強く、上方向に需給が偏った可能性

- **S安タッチ疑い**
  - 日中の価格挙動: 安値が制限値幅下限に到達
  - 需給の見方: 売り圧力が非常に強く、下方向に需給が偏った可能性

- **S高タッチ後張付き疑い**
  - 日中の価格挙動: 制限高値到達後、引けまで高値圏を維持
  - 需給の見方: 買い優位が継続し、売りの吸収が進んだ可能性

- **S安タッチ後張付き疑い**
  - 日中の価格挙動: 制限安値到達後、引けまで安値圏を維持
  - 需給の見方: 売り優位が継続し、買い戻しが弱かった可能性

- **S高寄天疑い**
  - 日中の価格挙動: 寄りで高値圏を付けた後に失速
  - 需給の見方: 序盤は買い先行だが、高値で利食い・戻り売りが優勢化

- **S安寄底疑い**
  - 日中の価格挙動: 寄りで安値圏を付けた後に持ち直し
  - 需給の見方: 序盤は売り先行だが、安値で買い戻しが優勢化

- **S高完全張り付き疑い**
  - 日中の価格挙動: ほぼ終日、制限高値近辺で固定
  - 需給の見方: 極端な買い超過状態で、売りの出方が限定的

- **S安完全張り付き疑い**
  - 日中の価格挙動: ほぼ終日、制限安値近辺で固定
  - 需給の見方: 極端な売り超過状態で、買い支えが限定的

#### 異常系

- **レンジ0**
  - 日中の価格挙動: 高値と安値が同じで値幅がほぼない
  - 需給の見方: 約定停滞や特殊な板状況の可能性
  - 具体的に疑われる現象:
    - 売買成立が非常に少なく、単一価格付近でのみ約定した
    - 値幅制限近辺で板が固定化し、実質的に価格が動かなかった
    - 流動性が低い時間帯・銘柄で、気配主導のまま引けた
    - 取引停止・売買規制など、通常連続売買と異なる市場状態が影響した

- **構造要因疑い**
  - 日中の価格挙動: 価格変化が通常日より不連続
  - 需給の見方: 分割・併合など、通常の売買以外の要因が混在している可能性
  - 具体的に疑われる現象:
    - 株式分割・併合・権利落ち等に伴う基準価格の変化
    - 大型のコーポレートアクションや制度要因による見かけ上のギャップ拡大
    - データソース側の補正タイミング差による一時的な不連続
    - ニュースイベントで寄り付き需給が急変し、通常の連続性が崩れた

## 5. 仕組編: 優先順位と解釈ルール

### 5-1. 優先順位の実務的理解

日足形状を読むときは、以下の順序で確認します。

1. 制限値幅関連
2. 異常系（レンジ0など）
3. 構造要因疑い
4. 形状・サイズ・方向

上位の項目ほど「通常の足型解釈より先に確認すべき注意事項」です。
この順序で見るべき理由は次のとおりです。

- **制限値幅関連を最優先にする理由:**
  - 価格形成が通常のレンジ内とは性質が異なり、通常のヒゲ解釈が効きにくいため
  - 実質的に「どちらに注文が偏ったか」が先に分かるため
- **異常系（レンジ0など）を次点にする理由:**
  - そもそも値動きがほぼ無い日は、形状分析の情報量が小さいため
  - 流動性・売買成立状況の確認を先に行う必要があるため
- **構造要因疑いをその次にする理由:**
  - コーポレートアクション等が混ざると、見かけの価格変化が需給を正しく表さないため
  - 通常日の比較軸（前日比・ATR比）が歪む可能性があるため
- **形状・サイズ・方向を最後に読む理由:**
  - ここは「通常条件下」で最も有効な解釈層であり、上位の注意信号を除外した後に精度が上がるため

### 5-2. 読み違いを防ぐポイント

- **長下ヒゲ陽線**は「終日強い」ではなく「一度売られてから戻した」
- **十字線**は「転換確定」ではなく「均衡・迷い」
- **構造要因疑い**は、ニュース・コーポレートアクション確認を優先

## 6. 応用編: 日足形状の限界と補完手順

### 6-1. 日足形状で分からないこと

日足形状は「1日の値動きの圧縮要約」です。以下の情報は含まれていません。

- どの時間帯で動いたか（寄り直後か、後場か、引け間際か）
- 同じ日足形状に至るまでの経路（先に急騰して失速したのか、逆か）
- 板の厚み・約定の連続性・VWAP乖離など、約定プロセスの詳細

つまり、日足形状は**結果**を伝えるものであり、**経過**は省略されています。

### 6-2. なぜ補完が必要か

- 同じ `長下ヒゲ陽線` でも、朝に急落して戻したケースと、後場に一時急落したケースでは意味合いが異なる
- 同じ `十字線` でも、低ボラで膠着したのか、乱高下後に同値へ戻ったのかで需給の質が異なる
- 日足だけでは、イベント発生時刻と価格反応の先後関係を確定できない

### 6-3. 実務での補完チェック（最小セット）

1. **分足（5分/15分）で時間帯を確認**
   - どの時間帯で高安を付けたかを確認する
2. **出来高の時間分布を確認**
   - 寄り付き集中か、後場主導かで参加者の性質を推定する
3. **ニュース・開示時刻を照合**
   - 価格変動の前後関係を確認し、因果の取り違えを防ぐ
4. **必要に応じて板・約定データを確認**
   - レンジ0や急変日の場合は、約定成立状況や気配主導の有無を確認する

## 7. 応用編: 具体例で確認（全例一覧）

各セクションで個別の例を挙げてきましたが、ここでは代表的なパターンをまとめて確認できます。

### 例1: `<極大>長下ヒゲ陽線`

- 相対値幅: とても大きい
- 形: 下で大きく売られた後に反発
- 引け: 買い優勢
- 読み: 日中は不安定だが、安値では買いが勝った

### 例2: `<小>十字線`

- 相対値幅: 小さい
- 形: 始値終値が接近
- 読み: 拮抗・様子見

### 例3: `下窓＋長上ヒゲ陰線`

- 寄り付きで上方向に離れて始まった
- その後に上値追いが失速し、引けは売り優勢
- 読み: 寄り直後の強気はあったが、高値帯の売り圧力に押し戻された可能性

### 例4: `上窓＋長下ヒゲ陽線`

- 寄り付きで下方向に離れて始まった
- 日中に下値を試した後、引けにかけて切り返し
- 読み: 悪い初動に対し、安値帯で買い需要が入りやすかった可能性

### 例5: `<極小>十字線`

- 日中の値幅が非常に小さい
- 始値と終値が近く、方向感がほぼ中立
- 読み: 強い拮抗または様子見で、次の材料待ちの可能性

### 例6: `<大>丸坊主陽線`

- ヒゲが短く、始値から終値まで上方向へ押し切る形
- 値幅も相対的に大きい
- 読み: 買い側の主導が明確で、日中に反対売買を吸収した可能性

### 例7: `<大>丸坊主陰線`

- ヒゲが短く、始値から終値まで下方向へ押し切る形
- 値幅も相対的に大きい
- 読み: 売り側の主導が明確で、戻り局面でも売りが優勢だった可能性

### 例8: `レンジ0`

- 高値と安値が同一で、1日の変動が極端に小さい
- 読み: 流動性低下、板固定化、規制要因などの確認を優先すべき局面

### 例9: `構造要因疑い`

- 価格変化が通常日より不連続で、見かけ上のギャップが大きい
- 読み: 分割・併合・権利落ちなどの可能性があるため、企業開示・公式情報の確認が必要

## 8. まとめ

- **基礎編の要点:**
  **陽線/陰線 + ヒゲ + 実体 + 値幅**で、その日の力関係はかなり読める
- **仕組編の要点:**
  日足形状は「サイズ」「形状」「方向」「異常系」を分けて作られており、解釈の再現性が高い
- **応用編の要点:**
  まず優先順位に従って注意信号を確認し、その後に足型を読むと解釈の誤差を減らせる
- **実務運用の要点:**
  日足形状は単体で断定せず、出来高・材料・イベントとセットで使う

### 次のステップ

- 保有銘柄や気になる銘柄の日足形状を実際に確認してみる
- 分足や出来高と見比べて、日足形状がどの程度「その日の要約」として機能しているか体感する
- 特殊ラベルが出た日はJPX公表情報と照合し、フラグの精度を確認する

以上を押さえると、日足形状を「なんとなくの印象」ではなく、
同じ基準で読み解けるようになります。
