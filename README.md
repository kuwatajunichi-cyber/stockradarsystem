# stockradarsystem

## 概要

Stock Radar System は、日本株市場を対象に**相対的に注目度が急浮上している銘柄群を、定量指標にもとづいて日次で抽出・可視化する**データパイプライン型システムである。

本システムは以下を目的とする。

* 日々の相場ノイズを排し、「どの銘柄に市場の視線が集まり始めているか」を把握する
* 主観・裁量を排除し、再現性のあるスクリーニングを行う
* 投資判断そのものではなく、「調査対象候補の抽出」に特化する

UI や裁量的分析は本システムの責務外とし、成果物は **XLSX / CSV 形式のデータ**として提供される。

* * *

## 対象市場・前提

* 対象市場：日本株（JPX 上場銘柄）
* 時系列単位：日次
* 実行方式：バッチ処理（定時）
* 実行環境：クラウド（GitHub Actions を想定）
* ローカル PC の常時稼働は不要

## ユニバース設計

### 1. 銘柄リストの統合

以下のソースを組み合わせて銘柄集合を構成する。

* **JPX 月次銘柄一覧**
  * 正式な分母定義の基準
* **MINKABU スクレイピング**
  * 市場注目銘柄の補足取得
* **yfinance**
  * 株価・出来高データ取得

* * *

### 2. ユニバース区分

#### 正式ユニバース

* JPX 月次銘柄一覧に含まれる銘柄
* 指標算出・ランキングの正規対象

#### Pending ユニバース

* MINKABU には存在するが、JPX 月次一覧に未掲載の銘柄
* IPO 直後・情報反映遅延などを想定
* 正式ユニバースとは**完全に分離して扱う**

#### 除外ユニバース

* データ不足
* 取得不能
* 明示的除外条件に該当

* * *

## 指標設計（概要）

### Relative Strength（RS）

* 市場全体（または定義済み比較群）に対する相対的パフォーマンス
* RSI（オシレーター）とは異なる概念
* オニール型 RS の思想を参考にしつつ、日本株向けに再定義

### 出来高偏差指標

* 銘柄固有の出来高分布に対する偏差
* 単純な前日比ではなく、**時系列平均との差分布**を重視
* 「市場参加者の急増」を検出するための補助軸

※ 指標は合成スコア化も可能だが、MVP では **個別指標を並列で提示**する。

* * *

## 成果物仕様

### XLSX

* LibreOffice / Excel 互換
* 各ユニバースごとにシート分離
* 各指標列は以下を満たす
  * ソート可能
  * フィルタ可能
* 先頭行・先頭列はラベルセル
  * 濃紺背景
  * 白文字
* 各指標に「ひとこと説明」を付記

### CSV

* 全ユニバース統合テーブル
* 分析・二次利用向け
* 型は明示的に定義

* * *

## 実行・運用方針

* 日次バッチは **失敗しても即時ロールバックしない**
* 成果物は
  * staging → latestの二段階コミット方式
* 実行ログ・実行IDを必ず保存
* 「止まらないこと」より「壊れないこと」を優先
